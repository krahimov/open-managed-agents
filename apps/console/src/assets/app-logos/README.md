Full-colour app logos shown by `<AppIcon>` (src/components/app-logos.tsx),
fetched once from Composio's public logo CDN (https://logos.composio.dev/api/<slug>)
and bundled so the common apps never wait on the network. linear.svg is the
simple-icons mark (see ../brand-marks/LICENSE.md) in Linear's brand indigo, since the CDN one
is a pale lilac that washes out on a light tile. File names are the
app key: lower-cased, letters and digits only. The logos are trademarks of
their owners and are used only to identify the app an agent connects to.
